# DNS (Domain Name System)

## 1. What is DNS?
DNS is like an address book for domain names. It helps find the IP address associated with a domain name.

## 2. Why do we need DNS?
Humans prefer domain names because they are easier to remember than IP addresses. Computers use IP addresses to communicate across networks and establish connections with servers. 

## 3. DNS vs Routing
- **DNS:** Helps find the IP address associated with a domain name.
- **Routing:** Determines where to forward network packets so they can move towards their destination IP address.

## 4. Example
When I type `youtube.com` in my browser:
1. DNS helps find the associated IP address.
2. The browser uses the IP address to establish a connection with the server.
3. Routing helps move packets towards their destination.
4. The server processes the request and sends a response.

## Key Takeaway
DNS helps with name-to-IP address resolution, while routing helps forward packets towards their destination.
